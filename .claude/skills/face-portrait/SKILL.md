# /face-portrait — Trait-card portrait

Формат утверждён owner'ом (2026-07-05) после трёх итераций: не проза,
не голая выгрузка метрик — **карточки признаков**. Каждая карточка идёт
по лестнице достоверности: измерение (1.0) → словарь (0.6) →
интерпретация человеческим языком (0.7) → плюсы/минусы.

## Workflow

1. Собери фото по батчам в буфер: `metrics_from_landmarks` на каждое
   (лестница авто-zoom внутри `_landmarks_from_photo`); отказы гейтов
   фиксируй с причиной, не фатальны.
2. Когда набор полный — один вызов `analyze_face_archive`
   (metrics_list=буфер): медианы, stability, support, **signature**,
   coverage, фоновые пометки.
3. Строй портрет ТОЛЬКО из карточек признаков (см. формат ниже),
   в порядке убывания |deviation_units| из signature; затем элементы
   и конституция; фоновые (scope=background) — отдельным блоком
   в конце с пояснением про линзу.
4. Если есть life-context от владельца — передай в
   `analyze_face_archive(life_context=...)` и показывай зелёным
   блоком ВНУТРИ карточки, поверх словаря.
5. Заверши: открытые вопросы для проверки жизнью (пограничные
   признаки), карта покрытия, дисклеймер.

## Формат карточки признака (обязательный)

```
### N. <Название признака>

🔬 Система увидела: <метрика> = <значение> (нейтраль <X>, порог <Y>,
   отклонение <Z> порогов) · подтверждение <n/m кадров> · <стабильность>

📖 Словарь [<система>, <источник>, 0.6]: «<дословная цитата из KB>»

💬 Человеческим языком [интерпретация, 0.7]:
   Что это значит: <1-2 предложения>
   Что это может значить: <вариативность, 1-2 предложения>
   Что это даёт человеку: <практическая польза черты>

➕ Плюсы: <короткий список>
➖ Минусы: <короткий список — из «слабость» той же словарной статьи
   и логичных следствий, помеченных как интерпретация>
```

## Жёсткие правила

- **Измерение и словарь не редактировать** — цифры и цитаты дословно.
- **Интерпретация (0.7) не противоречит словарю**, только раскрывает;
  формулировки вероятностные («склонен», «обычно», «может») — язык
  запрещённых слов см. no_determinism (никаких «будет/точно»).
- **Минусы обязательны в каждой карточке** — портрет без теней
  не принимается (урок owner-ревью).
- Фоновые чтения (dilated, fWHR — ширинная семья) НЕ выдавать как
  личные черты: отдельный блок «фон съёмки» с пояснением.
- Лоб из геометрии не читается (артефакт сетки), рот — только
  закрыто-ртные кадры, дворцы/текстура — нечитаемо (см. coverage).
- Пограничные значения (|deviation| < 1 порога) — карточка с пометкой
  «слабый сигнал» + вопрос владельцу для проверки жизнью.
- Life-context владельца главнее словаря — показывать поверх, словарь
  не удалять (провенанс).
- PII (имена, документы) — никогда в отчёты и репозиторий.
