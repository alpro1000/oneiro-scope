# /vocation-map — Карта призвания

Pattern: `vocation-map` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.

## Workflow

1. Собери birth data; место → `mcp__oneiro__validate_birth_data` /
   `search_city`. Время рождения критично (MC/дома) — без него спроси
   один раз, иначе ограничься знаками и достоинствами, о чём предупреди.
2. Вызови `mcp__oneiro__vocation_map(birth_date, birth_time,
   birth_timezone, lat, lon)`.
3. Примени `interprets.rules` каталога. Цитируемые чтения добирай из
   `mcp__oneiro__mc_in_sign`, `planet_in_house`, `planet_dignity`,
   `house_meaning` (0.9) — не сочиняй сам.
4. Собери **3-5 кластеров профессий**. Каждый кластер:
   - название + 3-6 конкретных ролей;
   - какие положения его поддерживают (цитируй placement → правило);
   - лестница: 🔬 расчёт (1.0) → 📖 традиция (0.9/0.8) → 💬 синтез (0.7).
5. Отдельно: **«сладкий стык»** — комбинация, задействующая сильнейший
   денежный сигнал И сильнейший сигнал самовыражения одновременно.
6. Отдельно: **«где не течёт»** — среды, гасящие сильные места карты
   (например наёмная иерархия при пустом 2-м с управителем в сделках).
7. Дисклеймер (не карьерный совет) — обязателен.

## Жёсткие правила

- Каждый кластер обязан цитировать конкретные положения — «просто
  список профессий» не принимается.
- Кластеры — русла, не приговоры: язык вероятностный, no_determinism.
- Если пользователь дал факты жизни (user_context, 0.9) — они главнее
  словаря, показывай поверх, но словарь не удаляй (провенанс).
