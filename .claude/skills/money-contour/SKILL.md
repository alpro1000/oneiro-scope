# /money-contour — Денежный контур карты

Pattern: `money-contour` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.

## Workflow

1. Собери birth data (дата, время, место). Место резолвь через
   `mcp__oneiro__validate_birth_data` / `mcp__oneiro__search_city` →
   lat/lon/timezone. Без времени рождения — спроси один раз; дома без
   времени ненадёжны, предупреди и предложи солярный fallback.
2. Вызови `mcp__oneiro__money_contour(birth_date, birth_time,
   birth_timezone, lat, lon)`.
3. Прочитай `interprets.rules` своего pattern-а из каталога и применяй
   ТОЛЬКО их поверх `computed`. Для цитируемых чтений (0.9) добирай
   `mcp__oneiro__house_meaning`, `planet_in_house`, `planet_dignity`.
4. Выведи блоками, каждый с лестницей достоверности:
   - **2-й дом** (стиль личного дохода): куспид → управитель → его
     дом/знак/достоинство → «куда течёт».
   - **8-й дом** (чужие деньги/инвестиции): то же + жильцы; Узел в 8-м
     отметь как вектор роста.
   - **Линчпин**: если `linked` — объясни «один мотор» своих и чужих
     денег (архетип дилера/инвестора/брокера).
   - **Колесо Фортуны**: дом/знак + диспозитор = зона «лёгкого» изобилия.
   - **Куда течёт / где не течёт** — 2-3 вывода с источниками.
5. Заверши дисклеймером (не финансовый совет) — обязателен.

## Формат каждого блока

```
🔬 Расчёт [astronomy, 1.0]: <факт из computed>
📖 Традиция [astrology_symbolic, 0.8-0.9]: <правило + цитата>
💬 Синтез [llm, 0.7]: <что это может значить — вероятностно>
```

## Жёсткие правила

- Расчёт не редактировать; трактовка не противоречит слою выше.
- Запрещённые слова — см. no_determinism («будет/точно» → «склонен /
  традиционно связывают»).
- Никаких сумм, тикеров, «инвестируй в X» — только русла и стили.
- Дисклеймер в конце обязателен.
