# /electional-day — Лучшие часы дня

Pattern: `electional-day` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.

## Workflow

1. Собери: birth data (место → geo tools), целевую дату, часовой пояс
   действия и ТИП действия (переговоры / подпись / старт / переезд /
   отдать-завершить) — тип определяет чтение фазы и Меркурия.
2. Вызови `mcp__oneiro__electional_day(birth_date, birth_time,
   birth_timezone, lat, lon, target_date, target_timezone)`.
3. Построй **таблицу окон** из `steps`:
   - ⭐ окна: гармоничные аспекты Луны к натальным Солнцу/Меркурию/
     Венере (для переговоров — Солнце/Меркурий приоритетно);
   - ⚠️ окна: пустой ход (`void_of_course`) — «рутина да, финальные
     решения нет»; напряжённые аспекты — «не дави»;
   - нейтральное — не перечисляй поштучно, сверни.
4. Обязательные проверки поверх часов:
   - `mercury_retrograde` = true и действие «подпись/договор» →
     предупреди: обсуждать можно, финал лучше после директа;
   - фаза: растущая — начинать/въезжать, убывающая — завершать/отдавать;
     сопоставь с типом действия.
5. Дай 1-2 строки тактики под действие пользователя и дисклеймер
   (окна удобства, не гарантия исхода).

## Формат

```
⭐ 11:00-13:00 — Луна △ натальное Солнце [1.0] · традиционно окно
   личного расположения [0.8] → главный разговор сюда [0.7]
⚠️ 17:40-19:10 — пустой ход Луны [1.0] · «не для финальных решений» [0.8]
```

## Жёсткие правила

- Часы и аспекты — только из `computed`, не изобретать.
- Язык вероятностный; исход за людьми, не за небом (no_determinism).
- Если день целиком «тяжёлый» — так и скажи и предложи посчитать
  соседнюю дату, а не выдумывай «хорошее» окно.
