# /character-face — Персонаж → лицо (обратный ход)

Pattern: `reverse-physiognomy` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.
Проверенный кейс: портрет 50-летнего Фандорина
(`docs/specs/fandorin-portrait/portrait-reverse-prompt.md`).

## Этический гейт (жёсткий, первым делом)

Субъект — ТОЛЬКО вымышленный персонаж (`fictional`) или сам
пользователь (`self`). Реальные третьи лица — отказ, всегда: KB
ethics_note (`western.json`) запрещает чтение третьих лиц, обратный ход
наследует запрет. Инструмент сам поднимет ошибку — не обходить.

## Workflow

1. Собери черты характера. Для литературного героя сперва собери КАНОН:
   внешность из первоисточника/справочников (веб-поиск), возраст,
   эпоху — канон первичен, физиогномика лишь дополняет.
2. Вызови `mcp__oneiro__reverse_physiognomy_prompt(traits=[...],
   subject_type="fictional"|"self", locale)`.
3. Построй **таблицу соответствий**: черта характера → тип по KB →
   черты лица → дословная цитата словаря + источник [0.6].
   `unmatched_traits` честно перечисли как непокрытые.
4. Собери из `face_feature_seed` + канона два промпта:
   - **RU и EN позитивный**: возраст/моложавость, форма лица, черты из
     KB, ключевые приметы канона (выдели ОБЯЗАТЕЛЬНЫЕ), эпоха/стиль;
   - **negative**: анти-черты (противоположные типы KB + нарушения
     канона).
5. Предложи генерацию: `scripts/generate_fandorin_portrait.py`
   (--provider openai|gemini, режимы generate/edit) как готовый раннер.
6. Дисклеймер: физиогномика — историческая традиция без научной
   валидности; это дизайн-инструмент образа, не описание реального
   человека.

## Жёсткие правила

- Цитаты словаря дословно, с источником; свои домыслы — только в слое
  «синтез 0.7» и явно помечены.
- Канон произведения главнее словаря при конфликте.
- PII реальных людей — никогда в промпты, отчёты, репозиторий.
