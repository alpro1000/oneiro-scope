# /life-pivots — Лента переломов (ретро-валидация)

Пакетный MCP-инструмент `life_pivots` снят с реестра срезом WP-10
(поверхность 47→19; владелец с тех пор вернул только чтение лица, 21).
Решение по `life_pivots` в силе — он остаётся снятым. Скилл собирает ту же
ленту КОМПОЗИЦИЕЙ из зарегистрированных инструментов. Единственный паттерн
с петлёй обучения на пользователе.

## Workflow

1. Собери birth data (место → `search_city` / `validate_birth_data`) и
   окно сканирования (по умолчанию: с ~18 лет до текущего года;
   максимум 60 лет).
2. **Фундамент:** `calculate_natal_chart(...)` — натальные позиции, дома,
   ASC/MC (если время известно).
3. **Датированные окна:** `compute_transits(birth_date, birth_time,
   birth_timezone, start, end, orb_deg=3.0)` кусками по ~5 лет (чтобы
   ответы оставались обозримыми). Из списка отбирай МЕДЛЕННЫЕ транзитные
   (Сатурн..Плутон) к Солнцу, Луне, натальному Сатурну и управителю ASC;
   циклы читаются прямо из аспектов:
   - возврат Сатурна (`saturn conjunction saturn`, ~29/58);
   - оппозиция Урана к Урану (~42) — середина жизни;
   - квадраты Сатурна к Сатурну (~7-летние такты).
4. **Маркеры переездов** — контакты с осями IC/ASC. Точных дат по углам
   композиция не даёт; оцени по годовой выборке `solar_return_chart`
   против натальных ASC/IC и помечай честно: strong = соединение с IC,
   possible = ASC/Луна, точность — год, не месяц.
5. Выведи **датированную таблицу окон**: даты (ГГГГ-ММ для аспектов,
   ГГГГ для угловых) · возраст · транзит · точка · тема по традиции ·
   маркер переезда. Символику — из `lookup(topic="transit_meaning",
   transiting=..., aspect=..., natal=...)` (0.9). Подавай как «окна для
   сверки», НЕ как утверждения о биографии.
6. Задай вопросы для сверки (2-4 самых сильных окна, не все сразу).
7. **Петля валидации** — сердце паттерна:
   - подтверждённое окно = convergence astronomy + user_context → HIGH;
     пометь его 🟢 и перескажи, что именно совпало;
   - опровергнутое окно = пометь и НЕ выкидывай (провенанс);
   - выведи калибровку: какие точки у этого человека срабатывают
     сильнее всего (например «у вас громче всего ASC и Луна») — эта
     строка передаётся в /decade-map как user_context.
8. Дисклеймер: карта не «делает» события, она размечает моменты.

## Жёсткие правила

- НИКОГДА не утверждай, что событие «было» — только «окно, которое
  традиционно совпадает с X; сверьте».
- Ответы пользователя (user_context, 0.9) главнее словаря; показывай
  поверх, словарь сохраняй.
- Подтверждённые факты биографии не записывать в репозиторий (PII) —
  только в ответ пользователю.
