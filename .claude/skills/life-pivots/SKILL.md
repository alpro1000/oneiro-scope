# /life-pivots — Лента переломов (ретро-валидация)

Pattern: `life-pivots` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.
Единственный паттерн с петлёй обучения на пользователе.

## Workflow

1. Собери birth data (место → geo tools) и окно сканирования (по
   умолчанию: с ~18 лет до текущего года; максимум 60 лет).
2. Вызови `mcp__oneiro__life_pivots(birth_date, birth_time,
   birth_timezone, lat, lon, from_year, to_year)`.
3. Выведи **датированную таблицу окон**: даты (ГГГГ-ММ) · возраст ·
   транзит · точка · тема по традиции · маркер переезда
   (strong = IC; possible = ASC/Луна). Символику — из
   `mcp__oneiro__transit_meaning` (0.9). Подавай как «окна для сверки»,
   НЕ как утверждения о биографии.
4. Задай `validation_questions` пользователю (2-4 самых сильных окна,
   не все сразу).
5. **Петля валидации** — сердце паттерна:
   - подтверждённое окно = convergence astronomy + user_context → HIGH;
     пометь его 🟢 и перескажи, что именно совпало;
   - опровергнутое окно = пометь и НЕ выкидывай (провенанс);
   - выведи калибровку: какие точки у этого человека срабатывают
     сильнее всего (например «у вас громче всего ASC и Луна») — эта
     строка передаётся в /decade-map как user_context.
6. Дисклеймер: карта не «делает» события, она размечает моменты.

## Жёсткие правила

- НИКОГДА не утверждай, что событие «было» — только «окно, которое
  традиционно совпадает с X; сверьте».
- Ответы пользователя (user_context, 0.9) главнее словаря; показывай
  поверх, словарь сохраняй.
- Подтверждённые факты биографии не записывать в репозиторий (PII) —
  только в ответ пользователю.
