# /decade-map — Декада по годам

Pattern: `decade-map` в
`backend/services/strategic/knowledge_base/analysis_patterns.json`.

## Workflow

1. Собери birth data (место → geo tools) и стартовый год (по умолчанию
   текущий). Горизонт 10 лет, максимум 12.
2. Вызови `mcp__oneiro__decade_map(birth_date, birth_time,
   birth_timezone, lat, lon, start_year, years)`.
3. Примени `interprets.rules` каталога:
   - дом Сатурна = что строится в этот ~2.5-летний блок (главный таймер);
   - дом Юпитера = зона расширения года;
   - `saturn_return` / `jupiter_return` / `angle_crossing` — назови
     явно, это опорные вехи;
   - символику транзита добирай из `mcp__oneiro__transit_meaning` (0.9).
4. Сгруппируй годы в **фазы-блоки** (2-3 года) с одной темой каждый:
   «ГОДЫ · возраст · ТЕМА» + 2-4 предложения, что поддержано и что
   проверить. Если возраст попадает в исследованные вехи (возврат
   Сатурна ~29/58, оппозиция Урана ~42) — сошлись на age_psychology (0.9).
5. Назови **окно старта** и **окно урожая** десятилетия с обоснованием.
6. Дисклеймер — обязателен: окна, не гарантии.

## Формат фазы

```
**ГГГГ-ГГГГ · возраст N-M · ТЕМА**
🔬 [1.0] <транзитные факты: дома, аспекты, вехи>
📖 [0.9] <традиционное чтение / age_psychology>
💬 [0.7] <синтез: на что направить>
```

## Жёсткие правила

- Никаких «в 2029 случится X» — только «окно традиционно
  благоприятнее для Y» (no_determinism).
- Каждая фаза цитирует конкретные транзиты из `computed`.
- Если известны подтверждённые события прошлого (после /life-pivots) —
  учитывай калибровку: какие точки у этого человека «работают громче».
