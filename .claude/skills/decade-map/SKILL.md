# /decade-map — Декада по годам

Пакетный MCP-инструмент `decade_map` снят с реестра срезом WP-10
(поверхность 47→19, решение владельца: 19 остаётся). Этот скилл собирает
ту же декаду КОМПОЗИЦИЕЙ из зарегистрированных инструментов — оркестрация
на вызывающей модели, детерминированные числа с сервера.

## Workflow

1. Собери birth data (место → `search_city` / `validate_birth_data`) и
   стартовый год (по умолчанию текущий). Горизонт 10 лет, максимум 12.
2. **Фундамент:** `calculate_natal_chart(...)` — натальные позиции, дома,
   ASC/MC. Без времени рождения дома не строятся — тогда декада идёт по
   аспектам к планетам, без домов, и скажи об этом явно.
3. **Точные даты:** `compute_transits(birth_date, birth_time,
   birth_timezone, start="ГГГГ-01-01", end="ГГГГ-12-31", orb_deg=3.0)`
   по каждому году декады. Из списка бери медленные транзитные
   (Юпитер..Плутон); ключевые вехи читаются прямо из него:
   - `saturn conjunction saturn` = возврат Сатурна (~29/58);
   - `jupiter conjunction jupiter` = возврат Юпитера (~каждые 12 лет);
   - соединения медленных с Солнцем/Луной/управителем MC — опорные точки.
4. **Дома по годам:** `solar_return_chart(...)` на каждый год даёт позиции
   медленных планет раз в год — положи их в НАТАЛЬНЫЕ дома по куспидам из
   п.2. Честно: это годовая выборка (окно), а не точная дата ингрессии —
   так и подавай: «в 2028 Сатурн идёт по вашему N-му дому».
5. Символику добирай из `lookup(topic="transit_meaning",
   transiting=..., aspect=..., natal=...)` (0.9).
6. Сгруппируй годы в **фазы-блоки** (2-3 года) с одной темой каждый:
   «ГОДЫ · возраст · ТЕМА» + 2-4 предложения, что поддержано и что
   проверить. Если возраст попадает в исследованные вехи (возврат
   Сатурна ~29/58, оппозиция Урана ~42) — сошлись на age_psychology (0.9).
7. Назови **окно старта** и **окно урожая** десятилетия с обоснованием.
8. Дисклеймер — обязателен: окна, не гарантии.

## Формат фазы

```
**ГГГГ-ГГГГ · возраст N-M · ТЕМА**
🔬 [1.0] <транзитные факты: даты аспектов, дома по годам, вехи>
📖 [0.9] <традиционное чтение / age_psychology>
💬 [0.7] <синтез: на что направить>
```

## Жёсткие правила

- Никаких «в 2029 случится X» — только «окно традиционно
  благоприятнее для Y» (no_determinism).
- Каждая фаза цитирует конкретные аспекты с датами из `compute_transits`;
  положения по домам — с оговоркой про годовую выборку.
- Если известны подтверждённые события прошлого (после /life-pivots) —
  учитывай калибровку: какие точки у этого человека «работают громче».
