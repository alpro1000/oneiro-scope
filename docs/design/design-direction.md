# OneiroScope — дизайн-направление

Извлечено из работающего прототипа `astrocartography.html`. Это не мудборд, а описание уже принятых решений — чтобы остальные экраны делались в том же языке, а не изобретались заново.

---

## Позиция

**Прибор, а не гадание.**

Продукт продаёт проверяемый расчёт: эфемериды с провенансом, орбисы, точность до угловых секунд. Интерпретацию делает модель или сам человек. Значит визуальный язык должен читаться как измерительный инструмент, а не как эзотерическая витрина.

Референсы — морские навигационные карты, гравированные астрономические атласы XIX века, латунные приборы, эфемеридные таблицы. **Не** космос из стоковых картинок, **не** фиолетово-бирюзовые градиенты, **не** таро-эстетика. Все конкуренты выкрашены во второе; первое их отличает.

Проверка на каждом экране: похоже это на страницу из атласа или на приложение-гороскоп? Нужно первое.

## Палитра

Ночная морская карта. Тёмная основа, латунный акцент, пергаментный текст.

```css
--abyss:     #071320;  /* фон, глубокая вода */
--shelf:     #0C1E2E;  /* контейнеры */
--panel:     #0A1B29;  /* панели приборов */
--land:      #152C3E;  /* заливка суши */
--landEdge:  #24445B;  /* контур берега */
--grat1:     #1B3549;  /* сетка, разделители */
--grat2:     #22415A;  /* рамки */

--parchment: #E7DDC7;  /* основной текст */
--muted:     #89A0B1;  /* второстепенный */
--dim:       #5C7385;  /* подписи, метки осей */

--brass:     #D2A64B;  /* акцент: заголовки, активное, метки */
--brassDim:  #8A6E32;  /* надзаголовки, служебные метки */
```

Акцент один — латунь. Второго акцентного цвета нет. Всё, что нужно выделить, выделяется латунью или яркостью пергамента, не новым оттенком.

### Планеты — классические металлы

## Типографика

Три гарнитуры, у каждой своя работа. Смешивать роли нельзя.

| Роль | Гарнитура | Где |
|---|---|---|
| Заголовки | **Bodoni Moda** | H1–H2, названия городов, поэтические врезки. Курсив — для акцента внутри заголовка |
| Интерфейс | **Instrument Sans** | Кнопки, абзацы, подписи, навигация |
| Данные | **IBM Plex Mono** | Градусы, координаты, орбы, время, версии, надзаголовки |

Принцип: **всё, что является числом или измерением, набирается моноширинным.** Это не украшение — это визуальный сигнал «здесь расчёт, а не мнение». Отличает вас от конкурентов сильнее, чем палитра.

Надзаголовки (eyebrow): Plex Mono, 10,5px, letter-spacing 0.22em, uppercase, цвет `--brassDim`.

Заголовки: letter-spacing −0.015em, line-height 0.94. Плотно, как на титуле атласа.

## Формы

- **Прямые углы.** `border-radius: 0` везде. Приборы и карты не скруглены.
- **Границы вместо теней.** 1px `--grat2`. Никаких box-shadow, никаких мягких свечений.
- **Заливка вместо обводки** только для суши и активных состояний.
- **Пунктир несёт смысл**, а не декорацию: сплошная линия — MC и Asc, пунктир — IC и Desc. Перекрестье курсора — точечный пунктир.
- Толщина линий 0.7–1.4px, подсветка активного — до 2.4px.

## Компоновка

Основной паттерн — **карта плюс панель прибора**:

```
┌─────────────────────────────┬──────────────┐
│                             │  ПРИБОР      │
│      область данных         │  показания   │
│      (карта, колесо,        │  блоками     │
│       таблица)              │  через 1px   │
│                             │  разделители │
├─────────────────────────────┴──────────────┤
│  легенда с переключателями                 │
├────────────────────────────────────────────┤
│  провенанс: движок, GMST, версия, req_id   │
└────────────────────────────────────────────┘
```

Сетка: `minmax(0,1fr) 300px`, на ширине ниже 900px схлопывается в одну колонку.

**Провенанс всегда виден.** Внизу каждого экрана с расчётом — строка с движком, версией эфемерид, `request_id`. Моноширинным, 10px, цветом `--dim`. Это не мелкий шрифт для юристов, это доказательство работы прибора, и оно должно быть на месте.

## Тон текста

- Заголовки короткие, без восторга. «Где что звучит» — да. «Раскройте тайну своей судьбы» — нет.
- Числа без округления в маркетинговую сторону: 0,63°, а не «почти точно».
- Разделять уверенное и предположительное. Геометрия проверяема, толкование — традиция. Это говорится прямо, а не прячется в сноску.
- Дисклеймер — обычным текстом рядом с результатом, не серым 8px в подвале.
- Русский без канцелярита и без эзотерического жаргона.

## Экраны к проработке

Что уже сделано: **астрокартография**. Использовать как эталон, не переделывать.

### Натальное колесо
Круг на тёмном фоне, латунная градусная шкала по внешнему краю, куспиды тонкими линиями `--grat2`, планеты глифами в цветах металлов. Аспекты — хордами внутри круга, цвет от планеты, пунктир для минорных. Справа — панель: таблица позиций моноширинным, таблица аспектов с орбами, достоинства. Пограничные положения помечены явно, а не подразумеваются.

### Лунный календарь
Сетка месяца. Фаза — заливкой круга, не иконкой. Лунные сутки числом моноширинным. Это единственные страницы под поисковый трафик, поэтому заголовки и текст должны читаться и без стилей.

### Прайс
Три колонки, прямые углы, разделители 1px. Латунью выделена одна рекомендуемая. Явно указано, что доступно в вебе, а что в коннекторе. Никаких «популярный выбор» и обратного отсчёта.

### `/connect`
Самая важная страница и самая скучная визуально. Два таба — Claude и ChatGPT. Требование платного тарифа чата написано **до** кнопки, не после. Кнопка копирования URL сервера. Скриншоты в рамках 1px.

### Кабинет
Плотный, приборный. Состояние подписки, сохранённые карты, история платежей. Кнопка отмены подписки — видимая, не спрятанная. Экспорт и удаление данных — отдельным блоком, не в подвале настроек.

## Проверка перед сдачей экрана

- Числа моноширинным?
- Углы прямые, тени отсутствуют?
- Акцент только латунный?
- Провенанс на месте?
- Работает на 380px?
- `prefers-reduced-motion` учтён?
- Не похоже на приложение-гороскоп?
